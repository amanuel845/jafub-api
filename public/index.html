GitHub API Playground V2

Interactive GitHub REST + GraphQL testing environment for Vercel.

RESTGraphQLFine-grained PATRate headersHistorycURLMobile

REST

Use /api/github/<path> for GET, POST, PUT, PATCH and DELETE. The catch-all proxy forwards to https://api.github.com and preserves query parameters.

GraphQL

POST /api/graphql accepts query, variables and optional operationName.

Authentication

Use a GitHub fine-grained PAT with minimum permissions. The UI stores it in localStorage for this browser. Never commit the token.

Endpoint catalog

Core, repositories, issues/PRs, search, organizations, Actions, gists/notifications, Git data, packages and security are represented. The custom path field can call endpoints not listed.

Headers

The proxy exposes rate-limit, request-ID, ETag, Link, Retry-After and deprecation/sunset headers when GitHub returns them.

Deployment

Push to GitHub, import into Vercel, and deploy with Node 20.x. The project includes package.json, vercel.json and vercel.js.
